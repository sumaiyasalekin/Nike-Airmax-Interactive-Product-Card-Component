# Nike Airmax Interactive Product Card Component

A modular, interactive e-commerce product card UI component built with dynamic color variants and state transitions for online sneaker stores.

##  Features

* **Interactive Hover States:** Cards dynamically transition from light mode (resting) to themed color backgrounds (active/hover state).
* **Color Variant System:** Includes pre-styled colorways (Black, Blue, Red) with dedicated color swatch pickers.
* **Modular Figma Components:** Built using Figma Component Variants and Auto Layout for rapid scalability and design system consistency.
* **Micro-Interactions:** Smooth perspective shift between tilted default product renders and profile active views.

##  Tech & Design Stack

* **Design Tool:** Figma (Component Variants, Smart Animate, Auto Layout)
* **Suggested Tech Stack:** React / Vue.js, Tailwind CSS, Framer Motion
